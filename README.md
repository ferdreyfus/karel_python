## Checkerboard Karel

For solving this program, we have 2 main functions. Paint Even, and Paint Odd Lines.
There are conditionals for the different scenarios that Karel may run into while painting checkerboard fields
such as collumn boards, 1 x 1 boards, single rows, and huge even or odd heighted boards.
